# Simple Socket File Transfer

基于 TCP 的简单文件传输示例，使用 C++ 实现客户端/服务端，通过 Socket 发送本地文件并在服务端保存。

## 功能

- 客户端连接服务端后，可交互式选择发送文件或退出
- 服务端支持多客户端并发（每个连接独立线程处理）
- 按固定协议传输：文件名 → 文件大小 → 文件内容
- 接收的文件保存在服务端工作目录下的 `files/` 文件夹中

## 传输协议

| 字段     | 长度              | 说明                         |
|----------|-------------------|------------------------------|
| 文件名   | 200 字节（定长）  | 仅发送文件名，不含路径       |
| 文件大小 | 8 字节            | `uint64_t`，网络字节序（大端） |
| 文件内容 | 剩余字节          | 按 4KB 缓冲区分块读写        |

## 环境要求

- Linux（使用 POSIX Socket API）
- C++17 编译器（如 g++、clang++）
- CMake 3.10 及以上

## 编译

```bash
mkdir -p build && cd build
cmake ..
make
```

编译完成后在 `build/` 目录下生成可执行文件 `server` 和 `client`。

## 使用方法

### 1. 启动服务端

```bash
cd build
./server
```

看到 `服务器启动成功，等待客户端连接...` 即表示监听成功。

### 2. 启动客户端

在另一个终端：

```bash
cd build
./client
```

按提示操作：

- 输入 `s`：发送文件，随后输入要传输文件的**绝对路径**
- 输入 `q`：退出客户端

### 3. 查看接收结果

服务端会在当前工作目录下自动创建 `files/` 目录，收到的文件以原文件名保存，例如：

```text
build/files/your_file.txt
```

## 配置

在 `tcp_config.h` 中可修改以下参数：

| 配置项                 | 默认值      | 说明           |
|------------------------|-------------|----------------|
| `SERVER_IP`            | `127.0.0.1` | 服务端 IP      |
| `SERVER_PORT`          | `10000`     | 监听端口       |
| `SERVER_FILE_DIR_NAME` | `files`     | 接收文件目录名 |
| `BUFF_SIZE`            | `4096`      | 读写缓冲区大小 |
| `FILENAME_DATA_LEN`    | `200`       | 文件名定长字段 |

修改配置后需重新编译。

## 注意事项

- 客户端需输入文件的**绝对路径**，否则可能无法正确打开文件
- 当前为学习/演示用途，未做加密、鉴权、断点续传等生产级特性
- 服务端与客户端需使用相同的 IP 和端口配置
